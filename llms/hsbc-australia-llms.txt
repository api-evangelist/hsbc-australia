# HSBC Bank Australia

> HSBC Bank Australia is a designated Consumer Data Right (CDR / Open Banking) data holder. Its only public API surface is the unauthenticated CDR Product Reference Data (PRD) API, which exposes HSBC Australia's banking products — home loans, deposit accounts, credit cards, and term deposits — as structured data conforming to the DSB Consumer Data Standards. The authenticated consumer data sharing surface is restricted to Accredited Data Recipients under the CDR security (FAPI) profile.

## APIs

- [CDR Product Reference Data API](https://www.hsbc.com.au/help/open-banking/): Public, unauthenticated Get Products and Get Product Detail. Base URL https://public.ob.hsbc.com.au/cds-au/v1. Requires the x-v version header (supports 4 and 5).
